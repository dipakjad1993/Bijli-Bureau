SECURITY · ZERO-DEP CORE · UPDATED 2026-10-12

Security: small surface, hashed evidence, signed when it matters

Supply chainCore engine (database.js + forensics.js + app.js) has zero npm runtime dependencies — SBOM in SBOM.json. Heavy libs (Tesseract OCR, Chart.js, jsPDF, QRCode, web-vitals) lazy-load on demand with SRI pins (see index.html integrity notes) and never block first paint.
Headers (prod)CSP (default self; scripts self + pinned CDNs; connect self + open.er-api + open-meteo + GA when configured), Referrer-Policy strict-origin-when-cross-origin, Permissions-Policy (camera self only), HSTS on batteryforensics.in. Meta fallbacks ship in index.html for static hosts.
Evidence integrityEvery run: SHA-256 over the cert payload + DPPpre JSON, printed in-app + PDF + QR page. Optional detached signature: Ed25519 (CLI, tools/generate-key.js) or ECDSA-P256 (WebCrypto fallback) — public key at /.well-known/bijlibureau-key.json + transparency-log entry. Verify: node tools/verify-signature.js <payload> <sig-b64>. Until a key is configured the UI honestly says "timestamped + SHA-256 hashed" — never "signed".
VaultIndexedDB origin-private; AES-GCM passphrase opt-in for dealers. No passwords server-side (magic-link SSO-lite for fleets — see tools/dealer-auth.js).
